БУСТ от nova (NB), ярлык «Bnova» - оптимизатор для слабого ноутбука (Windows 10/11)

ЧТО УМЕЕТ
- Показывает свободную оперативную память и освобождает её одной кнопкой БУСТ.
- Закрывает выбранные программы мягко (как крестиком; браузер закрывается вместе со всеми вкладками).
  Если в программе есть несохранённая работа, она сама спросит. Список можно менять галочками.
- Очищает память всех процессов и кэш Windows (нужны права администратора).
- Временно выключает фоновые службы SysMain, DiagTrack, WSearch (до перезагрузки) и включает схему питания
  "Высокая производительность". Кнопка "Вернуть службы и питание" возвращает всё обратно.
- Удаляет временные файлы (старше часа).
- Автоочистка памяти, когда её мало (в настройках).
- Настройки: автоочистка памяти, принудительное закрытие программ, ярлык на рабочем столе.
- Фон один: фиолетовый градиент без надписей (без смены фона).
- Запускается от имени администратора (Windows спросит разрешение).
- При первом запуске копирует себя в %LOCALAPPDATA%\Bnova и создаёт ярлык "Bnova" на рабочем столе.

КАК ПОЛУЧИТЬ bnova.exe БЕЗ УСТАНОВКИ RUST (через GitHub)
1. Создай репозиторий и загрузи все файлы из этого архива (Add file -> Upload files).
2. Вкладка Actions -> "set up a workflow yourself", вставь содержимое файла build.yml, Commit changes.
   (Файл должен оказаться в .github/workflows/ - редактор Actions создаёт папки сам.)
3. Через 5-10 минут справа на главной странице в Releases появится "Bnova (latest)" с чистым bnova.exe.
   Если сборка падает на правах: Settings -> Actions -> General -> Workflow permissions -> Read and write.

Файлы: main.rs (интерфейс), sys.rs (система), boost.c (нативный модуль), build.rs (сборка, иконка, запуск от админа).
